## Overview
This is Lab 1 of the Advanced Web Technologies course. The project is a small course catalog demonstrating the core concepts of the Next.js App Router: file-based routing, Server and Client Components, dynamic routes, and TypeScript typing. Data is currently served from a mocked in-memory source with a simulated delay; a real backend (FastAPI) will replace it in later labs.

## What's implemented

**Four routes** using file-based routing in the App Router:
`/` — home page with a link to the course list
`/about` — static page describing the project
`/courses` — course list rendered from mock data (Server Component)
`/courses/[id]` — dynamic course page with a like button

**Server and Client Components**:
`CourseCard` and page components are Server Components
`LikeButton` is the only Client Component (uses `'use client'` and `useState`)

**Dynamic routes** with `params` as a `Promise` (awaited) and `generateStaticParams` for pre-rendering all course pages at build time.

**Error and loading states**:
`app/courses/not-found.tsx` renders when an unknown course id is requested
`app/courses/[id]/loading.tsx` shows while a course page is loading

**Mock data source** in `lib/courses.ts` simulating a backend with a 300 ms delay.

**Shared navigation** in `app/layout.tsx` using `next/link`.

## Getting started
```bash
npm install
```

Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for production

```bash
npm run build
npm run start
```
The build output should show `/courses/[id]` prerendered as **SSG** — one static page per course, generated by `generateStaticParams`.

## Notes
The mock data source is temporary.
Likes are stored in local component state only and reset on page reload by design.
